# Lucra Event Listeners

Use SDK listeners to react to user changes and flow lifecycle events.

## Contest Listener

Listen for games/sports matchup events:

```ts
const unsubscribe = LucraSDK.addContestListener({
  onGamesMatchupCreated: (id: string) => {
    console.log('Games contest created:', id);
  },
  onSportsMatchupCreated: (id: string) => {
    console.log('Sports contest created:', id);
  },
  onGamesMatchupAccepted: (id: string) => {
    console.log('Games contest accepted:', id);
  },
  onSportsMatchupAccepted: (id: string) => {
    console.log('Sports contest accepted:', id);
  },
  onGamesMatchupCanceled: (id: string) => {
    console.log('Games matchup canceled', id);
  },
  onSportsMatchupCanceled: (id: string) => {
    console.log('Sports matchup canceled', id);
  },
  onGamesMatchupStarted: (id: string) => {
    console.log('Games matchup started', id);
  },
  onGamesMatchupStartedActive: (id: string) => {
    console.log('Games matchup started active', id);
  },
  onTournamentJoined: (id: string, gameId?: string) => {
    console.log('Tournament joined', id, gameId);
  },
  onAutoJoinedTournaments: (tournamentIds: string[]) => {
    console.log('Auto-joined tournaments', tournamentIds);
  },
  onMiniGameFinished: (event) => {
    // Fired when the user closes a mini game session (native `MiniGame.Finished`).
    console.log('Mini game finished', event);
  },
});

// Call this when you no longer need the listener (e.g., on unmount).
unsubscribe();
```

### `onMiniGameFinished`

Forwarded from the native `MiniGame.Finished` event. The payload mirrors the
parameters used to start the session:

```ts
type MiniGameFinishedEvent = {
  gameId?: string;
  gameMode?: MiniGameMode;
  amount?: number;
  matchupId?: string;
};
```

Use it to refresh balances, fetch updated matchup details, or surface rewards
once a session ends. It fires on both iOS and Android with identical payloads.
