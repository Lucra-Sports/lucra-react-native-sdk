# Reward Sheet

The SDK can automatically present a "You've won a reward!" bottom sheet over your app once the user is signed in and has unclaimed rewards. No manual invocation is required — the sheet appears on its own.

## Behavior

- Auto-shows once the user is signed in, if they have unclaimed tournament or achievement rewards.
- If no rewards exist, or the user isn't signed in, nothing is shown.
- When the user taps "Claim Now", the claim URL opens and the reward is marked as claimed.
- When the user dismisses the sheet, rewards are marked as viewed so they won't reappear.

## Disabling the Reward Sheet

Pass `allowRewardSheetToDisplay: false` to [`LucraSDK.init`](1.2.0_initialize_client.md) to globally suppress it on both platforms:

```ts
await LucraSDK.init({
  apiKey: 'YOUR_API_KEY',
  environment: LucraSDK.ENVIRONMENT.SANDBOX,
  allowRewardSheetToDisplay: false, // default: true
});
```

When disabled, the sheet never appears, regardless of unclaimed rewards.

## Android host requirement

On Android, auto-show attaches the reward UI to the currently resumed activity via AndroidX `FragmentManager`. Only activities that subclass `FragmentActivity` (including `AppCompatActivity`) can host the sheet. React Native's `ReactActivity` extends `AppCompatActivity`, so this is satisfied by default — if your app swaps in a different activity type for its foreground UI, ensure it still subclasses `FragmentActivity`.
