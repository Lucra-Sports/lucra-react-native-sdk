# Push Notifications

Push notifications require native registration to obtain a device token, then forwarding tapped notifications to Lucra.

## Register Device Token

### iOS

Register for remote notifications using your preferred library and pass the device token to Lucra.

```ts
import {
  registerDeviceTokenHex,
  registerDeviceTokenBase64,
} from '@lucra-sports/lucra-react-native-sdk';
import PushNotificationIOS from '@react-native-community/push-notification-ios';

PushNotificationIOS.addEventListener('register', async (token) => {
  await registerDeviceTokenHex(token);
});

// If your provider returns base64 tokens, use:
// await registerDeviceTokenBase64(token);

PushNotificationIOS.requestPermissions();
```

### Android

Pass the FCM token to either method — both forward the token string to Lucra as-is:

```ts
import { registerDeviceTokenHex } from '@lucra-sports/lucra-react-native-sdk';
import messaging from '@react-native-firebase/messaging';

const token = await messaging().getToken();
await registerDeviceTokenHex(token);

messaging().onTokenRefresh(async (newToken) => {
  await registerDeviceTokenHex(newToken);
});
```

## Handling Incoming Notifications

When the user taps a Lucra push notification, pass its data payload to
`handleLucraNotification`. It extracts the Lucra deeplink from the payload and
resolves it to flow info **without presenting any UI**:

```ts
type LucraFlowInfo = {
  flow: string; // e.g. 'matchupDetails', 'gamesMatchupDetails'
  matchupId?: string;
  gameId?: string;
  location?: string;
  gameMode?: string;
  amount?: number;
};

LucraSDK.handleLucraNotification(
  payload: Record<string, unknown>
): Promise<LucraFlowInfo | null>;
```

It returns `null` when the payload is not a Lucra notification, so it is safe
to call for every notification.

### iOS example

```ts
import { LucraSDK } from '@lucra-sports/lucra-react-native-sdk';
import PushNotificationIOS from '@react-native-community/push-notification-ios';

PushNotificationIOS.addEventListener('notification', async (notification) => {
  const isClicked = notification.getData().userInteraction === 1;
  if (isClicked) {
    const result = await LucraSDK.handleLucraNotification(
      notification.getData()
    );
    if (result?.matchupId) {
      // Headless: route to your own screen
      navigateToMyMatchupScreen(result.matchupId);
    }
  }

  notification.finish(PushNotificationIOS.FetchResult.NoData);
});
```

### Android example

```ts
import { LucraSDK } from '@lucra-sports/lucra-react-native-sdk';
import messaging from '@react-native-firebase/messaging';

messaging().onNotificationOpenedApp(async (remoteMessage) => {
  const result = await LucraSDK.handleLucraNotification(
    remoteMessage.data ?? {}
  );
  if (result?.matchupId) {
    navigateToMyMatchupScreen(result.matchupId);
  }
});
```

### Consuming the result

Headless integrations route to their own screens and can fetch the matchup
data with [headless functions](1.2.9_headless_interactions.md):

```ts
const result = await LucraSDK.handleLucraNotification(payload);
if (result?.matchupId) {
  const matchup = await LucraSDK.getMatchup(result.matchupId);
  // Render your own matchup results page
}
```

Integrations using Lucra UI present the resolved flow instead:

```ts
const result = await LucraSDK.handleLucraNotification(payload);
if (result) {
  await LucraSDK.present({
    name: result.flow,
    matchupId: result.matchupId,
  });
}
```

## Headless Deeplink Parsing

`parseLucraLink` is the same resolver for regular deeplinks: it resolves a
Lucra link to `LucraFlowInfo | null` without presenting UI. Use it instead of
[`handleLucraLink`](1.2.2_deeplinks.md) (which presents Lucra's full-screen
flow) when you want to route to your own screens:

```ts
const result = await LucraSDK.parseLucraLink(url);
if (result?.matchupId) {
  navigateToMyMatchupScreen(result.matchupId);
}
```
