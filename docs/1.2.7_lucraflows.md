# Lucra Flows

Lucra flows are full-screen or embedded UI experiences surfaced by the SDK.

## Full-Screen Flows

Use `LucraSDK.present` to display a full-screen flow.
`LucraSDK.present` returns a `Promise<void>`, so you can use `await` or `.then(...)`.

### Available Flows

```ts
const Flows = {
  ONBOARDING: 'onboarding',
  VERIFY_IDENTITY: 'verifyIdentity',
  PROFILE: 'profile',
  ADD_FUNDS: 'addFunds',
  WALLET: 'wallet',
  CREATE_GAMES_MATCHUP: 'createGamesMatchup',
  CREATE_SPORTS_MATCHUP: 'createSportsMatchup',
  WITHDRAW_FUNDS: 'withdrawFunds',
  PUBLIC_FEED: 'publicFeed',
  MY_MATCHUP: 'myMatchup',
  GAMES_CONTEST_DETAILS: 'gamesMatchupDetails',
  MATCHUP_DETAILS: 'matchupDetails',
  TOURNAMENT_DETAILS: 'tournamentDetails',
  DEMOGRAPHIC_COLLECTION: 'demographicCollection',
  HOME_PAGE: 'homePage',
  MINI_GAME: 'miniGame',
  MINI_GAMES_HOME: 'miniGamesHome',
  MINI_GAMES_PROFILE: 'miniGamesProfile',
  MINI_GAMES_REWARDS: 'miniGamesRewards',
  MINI_GAMES_MATCHUP_DETAILS: 'miniGamesMatchupDetails',
  ACHIEVEMENTS: 'achievements',
  NOTIFICATIONS: 'notifications',
  TRANSACTION_HISTORY: 'transactionHistory',
  CUSTOMER_SUPPORT: 'customerSupport',
  RESPONSIBLE_GAMING: 'responsibleGaming',
  HANDSHAKE_TOS: 'handshakeTOS',
} as const;
```

### Presenting Flows

```ts
import { LucraSDK, MiniGameMode } from '@lucra-sports/lucra-react-native-sdk';

await LucraSDK.present({ name: LucraSDK.FLOW.ONBOARDING });
await LucraSDK.present({ name: LucraSDK.FLOW.VERIFY_IDENTITY });
await LucraSDK.present({ name: LucraSDK.FLOW.PROFILE });
await LucraSDK.present({ name: LucraSDK.FLOW.ADD_FUNDS });
await LucraSDK.present({ name: LucraSDK.FLOW.WALLET });
await LucraSDK.present({ name: LucraSDK.FLOW.WITHDRAW_FUNDS });
await LucraSDK.present({ name: LucraSDK.FLOW.PUBLIC_FEED });
await LucraSDK.present({ name: LucraSDK.FLOW.MY_MATCHUP });
await LucraSDK.present({ name: LucraSDK.FLOW.DEMOGRAPHIC_COLLECTION });
await LucraSDK.present({ name: LucraSDK.FLOW.MINI_GAMES_HOME });
await LucraSDK.present({ name: LucraSDK.FLOW.MINI_GAMES_PROFILE });
await LucraSDK.present({ name: LucraSDK.FLOW.MINI_GAMES_REWARDS });
await LucraSDK.present({ name: LucraSDK.FLOW.NOTIFICATIONS });
await LucraSDK.present({ name: LucraSDK.FLOW.TRANSACTION_HISTORY });
await LucraSDK.present({ name: LucraSDK.FLOW.CUSTOMER_SUPPORT });
await LucraSDK.present({ name: LucraSDK.FLOW.RESPONSIBLE_GAMING });
```

The Mini Games matchup-details flow requires a matchup ID:

```ts
await LucraSDK.present({
  name: LucraSDK.FLOW.MINI_GAMES_MATCHUP_DETAILS,
  matchupId: 'MATCHUP_ID',
});
```

Flows that require parameters:

```ts
await LucraSDK.present({
  name: LucraSDK.FLOW.CREATE_GAMES_MATCHUP,
  gameId: 'PING_PONG',
});

await LucraSDK.present({
  name: LucraSDK.FLOW.CREATE_SPORTS_MATCHUP,
});

await LucraSDK.present({
  name: LucraSDK.FLOW.HOME_PAGE,
  locationId: 'LOCATION_ID', // optional — pre-select a location
});

await LucraSDK.present({
  name: LucraSDK.FLOW.GAMES_CONTEST_DETAILS,
  matchupId: 'MATCHUP_ID',
});

await LucraSDK.present({
  name: LucraSDK.FLOW.MATCHUP_DETAILS,
  matchupId: 'MATCHUP_ID',
});

await LucraSDK.present({
  name: LucraSDK.FLOW.TOURNAMENT_DETAILS,
  matchupId: 'TOURNAMENT_ID',
});

await LucraSDK.present({
  name: LucraSDK.FLOW.MINI_GAME,
  gameId: 'hoops-web',
  gameMode: MiniGameMode.ONE_VS_ONE,
  amount: 5, // optional buy-in; ignored for PRACTICE
  matchupId: 'MATCHUP_ID', // optional — join an existing matchup
  handlePostNavigation: true, // optional — auto-navigate to Matchup Details on session end
});

await LucraSDK.present({ name: LucraSDK.FLOW.ACHIEVEMENTS });
```

> `MINI_GAME` presents the full Lucra-managed mini game UI (loading → in-game
> WebView). This is the UI counterpart to the headless
> [`LucraSDK.startMiniGame`](6.1_mini_games_headless.md); use whichever fits your
> integration. The `MiniGame.Finished` event fires when the user closes the
> mini game session — see [Event Listeners](1.2.10_lucra_event_listener.md).
> Full per-flow details are in [Mini Games Flows](6.3_mini_games_flows.md).

### Flow Descriptions and Parameters

- `ONBOARDING`: Starts the user onboarding flow.
- `VERIFY_IDENTITY`: Prompts the user to verify identity.
- `PROFILE`: Opens the Lucra profile view.
- `ADD_FUNDS`: Opens the add funds flow.
- `WALLET`: Opens the wallet view to see balance, add/withdraw funds, and perform basic profile actions.
- `WITHDRAW_FUNDS`: Opens the withdraw funds flow.
- `PUBLIC_FEED`: Opens the sports public feed.
- `MY_MATCHUP`: Opens the user's matchup feed.
- `DEMOGRAPHIC_COLLECTION`: Prompts the user to complete demographics.
- `CREATE_GAMES_MATCHUP`: Create a games matchup. Optional params:
  - `gameId` (string): Your internal game identifier.
- `CREATE_SPORTS_MATCHUP`: Create a sports matchup.
- `GAMES_CONTEST_DETAILS`: Show a games matchup. Required params:
  - `matchupId` (string): Lucra matchup ID.
- `MATCHUP_DETAILS`: Show a generic matchup. Required params:
  - `matchupId` (string): Lucra matchup ID.
- `TOURNAMENT_DETAILS`: Show a tournament's details screen. Required params:
  - `matchupId` (string): Lucra tournament ID.
- `HOME_PAGE`: Opens the home page where users can create or browse games matchups and tournaments. Supports unauthenticated access. Optional params:
  - `locationId` (string): Pre-select a specific location.
- `MINI_GAME`: Present the full mini game UI. Params:
  - `gameId` (string, required): Mini game identifier.
  - `gameMode` (MiniGameMode, required): Session mode.
  - `amount` (number, optional): Buy-in amount; ignored for `PRACTICE`.
  - `matchupId` (string, optional): Join an existing matchup.
  - `handlePostNavigation` (boolean, optional): Defaults to `false`. When `true`, the SDK navigates to Mini Games Matchup Details automatically on a non-`PRACTICE`/non-`TOURNAMENT` session end with a resolved matchup, instead of dismissing.
- `MINI_GAMES_HOME`: Present the Mini Games home experience (profile pill, achievement card, game carousel, and featured tournament). Its sub-screens are also reachable directly via the flows below. No params.
- `MINI_GAMES_PROFILE`: Present the Mini Games profile (avatar, username, balance, stats, recent results). No params.
- `MINI_GAMES_REWARDS`: Present the Mini Games rewards screen (achievement rewards grouped by game). No params.
- `MINI_GAMES_MATCHUP_DETAILS`: Present the Mini Games matchup result screen. Required params:
  - `matchupId` (string): Lucra matchup ID.
- `ACHIEVEMENTS`: Open the achievements screen.
- `NOTIFICATIONS`: Open the in-app notification feed. No params.
- `TRANSACTION_HISTORY`: Open the user's transaction history. No params.
- `CUSTOMER_SUPPORT`: Open Lucra's customer support screen. No params.
- `RESPONSIBLE_GAMING`: Open Lucra's responsible gaming screen. No params.
- `HANDSHAKE_TOS`: Capture Terms of Service acceptance and complete a handshake sign-in. Present it **only** in response to a `tosNotAccepted` rejection from `signInWithHandshakeAuth` — it is not an entry point. See [Handshake Authentication](1.2.12_handshake_authentication.md#terms-of-service). No params.

### Presenting a parsed deeplink

Every flow the deeplink parsers can return is presentable, so `parseLucraLink` output can be handed straight to `present`:

```ts
const info = await LucraSDK.parseLucraLink(url);
if (info) {
  await LucraSDK.present({ name: info.flow, matchupId: info.matchupId });
}
```

An unrecognized flow name rejects the promise, so wrap the call if you forward names you did not get from the parser. See [Headless Deeplink Parsing](1.2.3_push_notifications.md#headless-deeplink-parsing).

### Dismissing Full-Screen Flows

Call `LucraSDK.closeFullScreenLucraFlows()` to programmatically dismiss any active Lucra full-screen UI:

```ts
setTimeout(() => {
  LucraSDK.closeFullScreenLucraFlows();
}, 10000);
```

## Embedded Flows (Experimental)

Use `LucraFlowView` to embed a flow inside your React Native UI:

```tsx
import { LucraFlowView, LucraSDK } from '@lucra-sports/lucra-react-native-sdk';

<LucraFlowView flow={LucraSDK.FLOW.PROFILE} className="flex-1" />
```

### Android Note (react-native-screens)

On Android with `react-native-screens`, embedded Compose views may disappear. If you use embedded flows, remount them when the screen is focused:

```tsx
import { useFocusEffect } from '@react-navigation/native';

const [flowKey, setFlowKey] = useState(Math.random().toString());

useFocusEffect(
  useCallback(() => {
    setFlowKey(Math.random().toString());
  }, [])
);

<LucraFlowView flow={LucraSDK.FLOW.PROFILE} key={flowKey} />
```
