# GYP Flows

[Lucra Flows setup](1.2.7_lucraflows.md)

Use `LucraSDK.present` to launch Games You Play flows.
`LucraSDK.present` returns a `Promise<void>`, so you can `await` flow launch completion.

## Home Page

`LucraSDK.FLOW.HOME_PAGE` is the landing page to find games to create — it also shows the available tournaments for the user. See [Lucra Flows](1.2.7_lucraflows.md#flow-descriptions-and-parameters) for parameters and usage.

## Create Games Matchup

```ts
await LucraSDK.present({
  name: LucraSDK.FLOW.CREATE_GAMES_MATCHUP,
  gameId: 'PING_PONG',
});
```

Required parameters:

- `name`: `LucraSDK.FLOW.CREATE_GAMES_MATCHUP`

Optional parameters:

- `gameId`: Your internal game identifier (string)

## Games Contest Details

```ts
await LucraSDK.present({
  name: LucraSDK.FLOW.GAMES_CONTEST_DETAILS,
  matchupId: 'MATCHUP_ID',
});
```

Required parameters:

- `name`: `LucraSDK.FLOW.GAMES_CONTEST_DETAILS`
- `matchupId`: Lucra matchup ID (string)
