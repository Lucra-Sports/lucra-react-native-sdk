# GYP Events

[Lucra Event Listener setup](1.2.10_lucra_event_listener.md)

Use the contest listener to receive Games matchup events.

```ts
const unsubscribe = LucraSDK.addContestListener({
  onGamesMatchupCreated: (id: string) => {
    console.log('Games contest created:', id);
  },
  onGamesMatchupAccepted: (id: string) => {
    console.log('Games contest accepted:', id);
  },
  onGamesMatchupCanceled: (id: string) => {
    console.log('Games matchup canceled', id);
  },
  onGamesMatchupStarted: (id: string) => {
    console.log('Games matchup started', id);
  },
  onGamesMatchupStartedActive: (id: string) => {
    console.log('Games matchup started active', id);
  },
});

// Call this when you no longer need the listener (e.g., on unmount).
unsubscribe();
```

## Event reference

- **`onGamesMatchupCreated`** — Fired immediately after the user creates a Games matchup. Carries the matchup `id` so you can cache or deep-link to it.
- **`onGamesMatchupAccepted`** — Fired when an invite is accepted (by your user or their opponent). Use the `id` to refresh state or notify stakeholders.
- **`onGamesMatchupCanceled`** — Fired when a matchup is canceled before completion. Carries the matchup `id` for cleanup or messaging.
- **`onGamesMatchupStarted`** — Fired when the matchup moves from pending to live play. Useful for starting timers or enabling score entry.
- **`onGamesMatchupStartedActive`** — Fired for an active matchup that's being viewed. Meaningful for participants who aren't the creator of the matchup.
