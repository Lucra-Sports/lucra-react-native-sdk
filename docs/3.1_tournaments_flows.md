# Tournament Flows

[Lucra Flows setup](1.2.7_lucraflows.md)

Use `LucraSDK.present` to navigate tournament experiences.
`LucraSDK.present` returns a `Promise<void>`, so you can `await` flow launch completion.

## View Tournament Details

Use `MATCHUP_DETAILS` to show a tournament matchup:

```ts
await LucraSDK.present({
  name: LucraSDK.FLOW.MATCHUP_DETAILS,
  matchupId: 'TOURNAMENT_MATCHUP_ID',
});
```

Required params:

- `name`: `LucraSDK.FLOW.MATCHUP_DETAILS`
- `matchupId`: Tournament matchup ID

## Home Page

`LucraSDK.FLOW.HOME_PAGE` is the primary entry point for tournaments — it lets users create or browse tournaments and games matchups, and supports unauthenticated access. See [Lucra Flows](1.2.7_lucraflows.md#flow-descriptions-and-parameters) for parameters and usage.
