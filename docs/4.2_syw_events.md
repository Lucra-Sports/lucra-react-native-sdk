# SYW Events

[Lucra Event Listener setup](1.2.10_lucra_event_listener.md)

Use the contest listener to receive Sports matchup events.

```ts
const unsubscribe = LucraSDK.addContestListener({
  onSportsMatchupCreated: (id: string) => {
    console.log('Sports contest created:', id);
  },
  onSportsMatchupAccepted: (id: string) => {
    console.log('Sports contest accepted:', id);
  },
  onSportsMatchupCanceled: (id: string) => {
    console.log('Sports matchup canceled', id);
  },
});

// Call this when you no longer need the listener (e.g., on unmount).
unsubscribe();
```

## Event reference

- **`onSportsMatchupCreated`** — Fired immediately after the user creates a Sports matchup. Carries the matchup `id` so you can cache or deep-link to it.
- **`onSportsMatchupAccepted`** — Fired when an invite is accepted (by your user or their opponent). Use the `id` to refresh state or notify stakeholders.
- **`onSportsMatchupCanceled`** — Fired when a matchup is canceled before completion. Carries the matchup `id` for cleanup or messaging.
