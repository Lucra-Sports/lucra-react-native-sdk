# Rewards & Achievements

Achievements are milestone-based awards users earn by completing in-game or in-tournament actions (score thresholds, win counts, placements, or participation). Rewards are earned from tournament and mini game matchup finishes. Both surface a claim/view state that you can drive with `LucraSDK.present` or the headless functions below.

## Entry Point

Use `LucraSDK.FLOW.ACHIEVEMENTS` to open the SDK's full-screen achievements list:

```ts
await LucraSDK.present({ name: LucraSDK.FLOW.ACHIEVEMENTS });
```

See [Lucra Flows](1.2.7_lucraflows.md) for full presentation details.

## Headless API

[Lucra Headless setup](1.2.9_headless_interactions.md)

These APIs fetch and mutate the current user's non-monetary rewards (earned from
tournaments and mini game matchups) and achievements, without showing Lucra UI.
All calls require `LucraSDK.init` to be completed and the user configured.

> These are experimental surfaces that map to the native iOS/Android headless
> reward & achievement APIs. Behavior is identical across platforms.

### Rewards

#### Get user tournament rewards

Returns rewards earned from tournament finishes and mini game matchup finishes.

```ts
import { LucraSDK, type LucraTournamentReward } from '@lucra-sports/lucra-react-native-sdk';

const rewards: LucraTournamentReward[] = await LucraSDK.getUserTournamentRewards({
  tournamentId, // optional — scope to one matchup/tournament; omit for all
  viewed,       // optional boolean filter
  claimed,      // optional boolean filter
});
```

#### Claim a reward

```ts
await LucraSDK.claimReward(rewardId);
```

#### Mark a reward viewed

```ts
await LucraSDK.markRewardViewed(rewardId);
```

#### `LucraTournamentReward`

```ts
type LucraTournamentReward = {
  id: string;          // reward id
  place: number;
  matchupId?: string;
  matchupTitle?: string;
  claimedAt?: string;  // ISO-8601
  viewedAt?: string;   // ISO-8601
  reward?: LucraCatalogReward;
};

type LucraCatalogReward = {
  id: string;
  type?: string;
  title: string;
  descriptor?: string;
  iconUrl?: string;
  bannerIconUrl?: string;
  disclaimer?: string;
  discountCode?: { code?: string; claimUrl?: string };
  freeItem?: { itemId?: string };
};
```

### Achievements

#### Get user achievements

```ts
import { LucraSDK, type LucraAchievement } from '@lucra-sports/lucra-react-native-sdk';

const achievements: LucraAchievement[] = await LucraSDK.getUserAchievements({
  viewed,                 // optional boolean filter
  claimed,                // optional boolean filter
  includeNoProgress,      // optional, defaults to true
});
```

#### Claim an achievement

```ts
await LucraSDK.claimAchievement(userAchievementId);
```

#### Mark an achievement viewed

```ts
await LucraSDK.markAchievementViewed(userAchievementId);
```

#### `LucraAchievement`

```ts
type LucraAchievement = {
  id: string;
  userId: string;
  achievementId: string;
  tenantId: string;
  matchupId?: string;
  userGameScoreId?: string;
  isEarned: boolean;
  earnedAt?: string;   // ISO-8601
  viewedAt?: string;   // ISO-8601
  claimedAt?: string;  // ISO-8601
  currentProgress: number; // 0..100, for a progress bar; 100 once isEarned is true
  currentValue: number;    // raw progress toward the goal, e.g. a best score of 261
  targetValue: number;     // the goal the criteria sets, e.g. 700; 0 when unresolved
  achievement?: LucraAchievementDefinition;
};

type LucraAchievementDefinition = {
  id: string;
  title: string;
  description?: string;
  iconUrl?: string;
  criteriaType: 'scoreThreshold' | 'winCount' | 'placementCount' | 'participationCount';
  criteriaConfig: {
    threshold?: number;
    conditionOperator?: 'gte' | 'lte' | 'eq';
    count?: number;
    place?: number;
  };
  gameId?: string;
  catalogReward?: LucraCatalogReward;
};
```

#### Reading progress

Every achievement carries three progress values on both platforms. Use the raw pair for any text you render and the percentage only for a progress bar:

- `currentValue` — the user's raw progress, e.g. a best score of `261`.
- `targetValue` — the goal the criteria sets, e.g. `700`. `0` when the goal could not be resolved; treat that as "no goal to show" rather than dividing by it.
- `currentProgress` — progress-bar fill only, `0..100`. Always `100` once `isEarned` is `true`.

```ts
const readout =
  achievement.targetValue > 0
    ? `${Math.trunc(achievement.currentValue)} / ${Math.trunc(achievement.targetValue)}`
    : null;
```

`currentProgress` is rounded down to a whole percent, so rebuilding a point total from it (`currentProgress / 100 * targetValue`) can come up short by almost `targetValue / 100` points — read `currentValue` instead. Both raw values can be fractional; the example truncates with `Math.trunc` rather than rounding, so a value just short of the goal never reads as having reached it.

### Error handling

These calls reject with the standard lowercase Lucra error codes
(see [Headless functionality](1.2.9_headless_interactions.md)): `notInitialized`,
`notAllowed`, `apiError`, `unknownError`.

```ts
try {
  await LucraSDK.claimReward(rewardId);
} catch (e: any) {
  switch (e.code) {
    case 'notInitialized':
      await LucraSDK.present({ name: LucraSDK.FLOW.ONBOARDING });
      break;
    default:
      console.warn(e);
  }
}
```
