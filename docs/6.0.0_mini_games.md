# Mini Games

Mini Games are browser-based games supplied by Lucra (e.g. `'hoops-web'`, `'runaway-web'`) that can be launched in practice, 1v1, free-for-all, or tournament mode. Here you'll find the relevant Lucra Flows, Mini Game Events, and headless functions to integrate them into your app.

## Entry Points

- **`MINI_GAME` flow** — fully Lucra-managed: loading screen, pre-flight checks, and the game WebView, all presented for you. See [Mini Games Flows](6.3_mini_games_flows.md).
- **Headless `startMiniGame`** — returns session data (`url`, `sessionId`, optional `matchupId`); you own the surrounding UI, but the returned `url` must still be hosted in `MiniGameWebView` or a WebView of your own. See [Mini Games Headless Functions](6.1_mini_games_headless.md) and [Mini Games WebView](6.4_mini_games_webview.md).
- Present matchup details after the game ends using `LucraSDK.present`.

## Prerequisites

### Peer Dependencies

Mini Games requires two additional peer dependencies:

```sh
npm i -S react-native-webview react-native-haptic-feedback
```

| Package | Minimum Version |
|---------|----------------|
| `react-native-webview` | `>=13.0.0` |
| `react-native-haptic-feedback` | `>=2.0.0` |

### GeoComply Preloading

Before starting a mini game, preload GeoComply tokens for the relevant buy-in context. This should be called early (e.g., when the mini game screen mounts) to avoid delays at game start:

```ts
import { LucraSDK, GeoComplyContext } from '@lucra-sports/lucra-react-native-sdk';

LucraSDK.preloadGeoToken(GeoComplyContext.CASH_BUY_IN);
```

`GeoComplyContext` values:

| Value | Description |
|-------|-------------|
| `GeoComplyContext.FREE_BUY_IN` | Free-to-play matchups |
| `GeoComplyContext.CASH_BUY_IN` | Cash buy-in matchups |
| `GeoComplyContext.DEPOSIT` | Deposit flow |
| `GeoComplyContext.WITHDRAWAL` | Withdrawal flow |
