# Mini Game Events

[Lucra Event Listener setup](1.2.10_lucra_event_listener.md)

## Listening for mini game events

### `onMiniGameFinished`

Fired when the user closes a mini game session, for every mode (practice, 1v1, free-for-all, or tournament). Forwarded from the native `MiniGame.Finished` event.

```ts
import { LucraSDK } from '@lucra-sports/lucra-react-native-sdk';

const unsubscribe = LucraSDK.addContestListener({
  onMiniGameFinished: (event) => {
    console.log('Mini game finished', event);
    // Refresh wallet balance, refetch rewards/achievements, etc.
  },
});

// Call this when you no longer need the listener (e.g., on unmount).
unsubscribe();
```

## Event reference

### `MiniGameFinishedEvent`

```ts
type MiniGameFinishedEvent = {
  gameId?: string;
  gameMode?: MiniGameMode;
  amount?: number;
  matchupId?: string;
};
```

| Field | Description |
|-------|-------------|
| `gameId` | Identifier of the game that just finished (e.g. `'hoops-web'`). |
| `gameMode` | The mode the session ran in. See `MiniGameMode` in [Mini Games Headless Functions](6.1_mini_games_headless.md). |
| `amount` | Wager amount in USD. Omitted for practice sessions. |
| `matchupId` | Associated matchup ID. Omitted for practice sessions. |

Fires with identical payloads on iOS and Android.
