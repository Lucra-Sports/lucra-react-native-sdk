# Mini Games Flows

[Lucra Flows setup](1.2.7_lucraflows.md)

Use `LucraSDK.present` to launch Mini Games experiences.
`LucraSDK.present` returns a `Promise<void>`, so you can `await` flow launch completion.

## Play a Mini Game

```ts
await LucraSDK.present({
  name: LucraSDK.FLOW.MINI_GAME,
  gameId: 'hoops-web',
  gameMode: MiniGameMode.ONE_VS_ONE,
  amount: 5, // optional buy-in; ignored for PRACTICE
  matchupId: 'MATCHUP_ID', // optional — join an existing matchup
});
```

Required parameters:

- `name`: `LucraSDK.FLOW.MINI_GAME`
- `gameId`: Mini game identifier (string), e.g. `'hoops-web'`, `'runaway-web'`. Omit for `TOURNAMENT` mode — the SDK resolves it from the matchup.
- `gameMode`: `MiniGameMode` value.

Optional parameters:

- `amount`: Buy-in amount in dollars. Ignored for `PRACTICE`.
- `matchupId`: Existing matchup to join. Omit to create a new one; required to join a `TOURNAMENT` matchup.

> This is the UI-managed counterpart to the headless [`LucraSDK.startMiniGame`](6.1_mini_games_headless.md#start-mini-game). The SDK handles the loading screen, pre-flight checks (sign-in, KYC, funds), and renders the game WebView for you — use whichever fits your integration. Listen for `onMiniGameFinished` to know when the session ends, see [Mini Game Events](6.2_mini_game_events.md).

## Mini Games Home

```ts
await LucraSDK.present({ name: LucraSDK.FLOW.MINI_GAMES_HOME });
```

Required parameters:

- `name`: `LucraSDK.FLOW.MINI_GAMES_HOME` (no additional parameters)

Presents the Mini Games hub: profile pill, achievement progress, a game carousel, and a featured tournament. Profile, Rewards, and matchup details are all reachable from here without you wiring up navigation — those screens are also available directly via the flows below.

## Mini Games Profile

```ts
await LucraSDK.present({ name: LucraSDK.FLOW.MINI_GAMES_PROFILE });
```

Required parameters:

- `name`: `LucraSDK.FLOW.MINI_GAMES_PROFILE` (no additional parameters)

Shows avatar, username, balance, stats, and recent results.

## Mini Games Rewards

```ts
await LucraSDK.present({ name: LucraSDK.FLOW.MINI_GAMES_REWARDS });
```

Required parameters:

- `name`: `LucraSDK.FLOW.MINI_GAMES_REWARDS` (no additional parameters)

Shows achievement rewards grouped by game. See [Achievements](5.0_achievements.md) for the headless equivalent.

## Mini Games Matchup Details

```ts
await LucraSDK.present({
  name: LucraSDK.FLOW.MINI_GAMES_MATCHUP_DETAILS,
  matchupId: 'MATCHUP_ID',
});
```

Required parameters:

- `name`: `LucraSDK.FLOW.MINI_GAMES_MATCHUP_DETAILS`
- `matchupId`: Lucra matchup ID (string)

Shows the mini games–themed result screen for a completed or pending matchup. See [Showing Matchup Details After Game](6.1_mini_games_headless.md#showing-matchup-details-after-game) to present this after a headless `startMiniGame` session ends.

---

All Mini Games flows require the user to be signed in and Mini Games to be enabled for your tenant — the SDK routes to onboarding automatically when needed.
